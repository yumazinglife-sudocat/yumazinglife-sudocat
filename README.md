## ⚡ Engineering Principles

| Principle | Practical translation |
|---|---|
| **Useful beats flashy** | AI should solve a real problem—not merely autocomplete an apology. |
| **Simple beats clever** | Clever code is fun until it pages you at 3:07 AM. |
| **Measure before optimizing** | Except coffee. Coffee is pre-optimized. |
| **Tests are documentation** | They explain what the code promised before reality became involved. |
| **Ship, observe, improve** | Production is where assumptions finally receive peer review. |
